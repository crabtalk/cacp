Expand description

What an ACP agent serves.

Only initialize, new_session and prompt are required. Every other method defaults to replying “method not found”, so an agent that does not implement a capability declines it instead of leaving the client waiting — advertise what you do implement in proto::InitializeResponse::agent_capabilities.
