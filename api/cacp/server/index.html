Serve the agent side of ACP.

Implement Agent and hand it to one of the serve_* functions. You get back a ClientConn for calling the client — reporting progress, asking permission, reading files through the editor.

Every optional method of Agent defaults to replying “method not found”, so a client asking for something you do not serve gets a clean refusal instead of waiting forever.
