Expand description

What an ACP client serves.

Only session_update and request_permission are required. fs/*, terminal/* and elicitation/* default to replying “method not found”, so an agent that asks for something you do not serve gets a clean refusal and carries on — declare what you do serve in ClientCapabilities.

Required Methods§

Source

fn session_update( &self, notification: SessionNotification, ) -> impl Future<Output = ()> + Send

Progress for a turn: message chunks, tool calls, plans, mode changes. Awaited in wire order, so keep it to a channel send.

Source

fn request_permission( &self, request: RequestPermissionRequest, ) -> impl Future<Output = Result<RequestPermissionResponse>> + Send

Ask the user to authorize a tool call. Answering may take as long as the user does — it will not stall the update stream.

fn connect_mcp( &self, request: ConnectMcpRequest, ) -> impl Future<Output = Result<ConnectMcpResponse>> + Send

Open an MCP connection on the agent’s behalf. Serve this and the agent can use servers it could never reach itself — ones behind the editor’s own credentials or process.

Source

fn message_mcp( &self, request: MessageMcpRequest, ) -> impl Future<Output = Result<MessageMcpResponse>> + Send

Forward one MCP call down a connection and hand back what the server said, unread.

Source

fn notify_mcp( &self, notification: MessageMcpNotification, ) -> impl Future<Output = ()> + Send

The same tunnel as message_mcp, for MCP messages that want no reply.
