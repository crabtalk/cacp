1//! A compact implementation of the [Agent Client Protocol][acp] v1.
2//!
3//! Two traits carry the protocol. An agent implements [`Agent`] and gets a
4//! [`ClientConn`] to call the client with; a client implements [`Client`]
5//! and gets an [`AgentConn`] to call the agent with. Routing is provided —
6//! you write handlers, never a dispatch table.
7//!
8//! Every optional method defaults to replying "method not found", so a peer
9//! that asks for something you do not serve gets a clean refusal rather than
10//! waiting forever.
11//!
12//! Each side is a feature, and both are on by default. Turn off the one you
13//! do not implement:
14//!
15//! ```toml
16//! cacp = { version = "0.0.1", default-features = false, features = ["client"] }
17//! ```
18//!
19//! Depend on `cacp-proto` instead if you only need the wire types; it pulls
20//! in no async runtime.
21//!
22//! [acp]: https://agentclientprotocol.com
23
